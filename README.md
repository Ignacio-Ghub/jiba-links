# jiba-links

Página "link in bio" de Jesús Ignacio Briceño Alarcón (JIBA), usada en el bio de Instagram.

Vive desplegada en Vercel, separada del sitio principal (ignaciobriceno.com), para que no dependa de WordPress y abra sin problemas en el navegador in-app de Instagram.

## Archivos
- `index.html` — página completa (HTML + CSS + JS inline, sin build step)
- `logo.png` — logo JIBA, usado en el footer
- `profile.jpg` — foto de perfil, usada en el avatar circular

## Editar
Es HTML estático puro, sin frameworks ni dependencias. Cualquier editor de texto sirve. No hay `npm install` ni build.

## Desplegar
Conectado a Vercel. Cualquier push a `main` dispara un deploy automático a producción.
